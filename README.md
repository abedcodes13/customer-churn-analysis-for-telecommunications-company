# Customer Churn Analysis — Telecommunications Company

Customer segmentation and churn prediction for a telecommunications company, using
clustering (K-Means) and a neural network (ANN) to identify churn drivers and inform
retention strategy.

## Project Overview

High customer churn is a persistent challenge in telecoms. This project analyses a
customer dataset to:

1. **Segment customers** by behavioural similarity (clustering)
2. **Predict churn** for individual customers (ANN classification)
3. Turn both into **actionable retention recommendations**

The project runs in three stages — Planning & Setup, Data Preparation & Modeling, and
Prediction & Reporting — tracked in Jira (`SCRUM` project) with the Project Charter
in Confluence.
